## 🚀 Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npx vite preview --port 4173
```

## 🌐 Deploy to Vercel (1-Click)

1. Push this repository to your GitHub account:
   ```bash
   git add .
   git commit -m "feat: complete professional portfolio"
   git branch -M main
   git remote add origin https://github.com/anuptiwari7033/portfolio.git
   git push -u origin main
   ```
2. Go to [Vercel](https://vercel.com/) and click **"Add New Project"**.
3. Import your GitHub repository (`portfolio`).
4. Click **Deploy**. Vercel will automatically detect Vite and deploy your portfolio live with a `.vercel.app` URL!
